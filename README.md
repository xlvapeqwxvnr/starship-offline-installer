## 📖 About Starship

Starship is a free, open-source, blazing-fast cross-shell prompt for Windows, macOS, and Linux. Display relevant contextual information in your terminal including git branch status, programming language versions, cloud credentials, and more, with minimal configuration. Starship works with bash, zsh, fish, PowerShell, and most other shells, making it the universal terminal prompt enhancement.

---

## ❌ Problem: Starship is hard to access

- **Shell Configuration** — Requires modifying shell configuration files to activate
- **Nerd Font Required** — Full icon display requires installing and configuring a Nerd Font
- **Customization Depth** — Default configuration adequate but full power requires learning TOML config
- **Performance Variance** — Very large git repositories can slow prompt rendering
